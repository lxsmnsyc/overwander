# Incubators

## Goal

More than one egg earning steps. Recommended: a fixed number of slots per player (for example 3), raised by a key item or quest, each egg in a slot earning the steps the buddy walks (possibly half, so the buddy keeps its value). The other model is a spendable Incubator item plus an Infinite Incubator from a quest. Step credit runs through `creditedEggSteps` in `src/model/egg.ts` and the step report in `src/server/eggs.ts`, at the same clamp.
