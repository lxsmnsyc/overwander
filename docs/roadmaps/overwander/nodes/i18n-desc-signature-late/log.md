# Log: i18n-desc-signature-late

- Same loader and header as the early part: `readAbilities` reads every `text/*/abilities/**/*.yaml` overlay with `name` and `description`, so no code changed. The files carry the generator's two-line header, and `pnpm official-names` leaves them untouched.
- Method: English lines dumped with the official ja and es names of every move, ability, item and species they mention; one table per region (`key | ja name | ja line | es name | es line`); a build script wrote the YAML and refused missing, extra or duplicate keys. A check script then looked for numbers dropped or added (the digit 1 and 0 ignored, since ja and es spell "once" and "a stage" in words), full stops (。 in ja), kanji in ja, em-dashes, double spaces, a Spanish line ending on `Esp.`, a name equal to the English, and collisions of each coined name with every official ability, move, item and species name of the locale and with every other coined name of all ten regions (katakana folded to hiragana, accents and spaces dropped). A second pass listed official names that contain a coined name or sit inside it.
