# Settings

**Settings** sits at the foot of the menu, under the keys and beside the day
and night switch. Nearly everything on it belongs to the **machine rather than
the account**: two browsers signed in as the same trainer can disagree, and none
of it reaches the server. Sign out and it is still set the way you left it; open
the game on a phone and that phone starts fresh. **Security** is the one
exception, below.

It is laid out in sections, and it opens on whichever one was last left open.

| Section      | Setting                | What it does                                                                                       |
| ------------ | ---------------------- | -------------------------------------------------------------------------------------------------- |
| **Display**  | **Dark mode**          | Draws the game in its night colours. Follows the machine until you choose                          |
|              | **Reduce motion**      | Holds the decoration still: fades, transitions, and the idle a pokemon breathes at                 |
|              | **Clock**              | Whether times read as 24-hour or 12-hour                                                           |
| **Controls** | **Up** to **Menu**     | Which key walks each way, which key acts on what you face, and which key opens the menu bar        |
| **World**    | **Grid lines**         | Rules a line round every cell of the board                                                         |
|              | **Chunk lines**        | Rules a line where one chunk meets the next                                                        |
|              | **World map grid**     | Rules every chunk on the world map, the detailed map as well                                       |
|              | **Flat board**         | Draws the board flat from straight above on a wide screen too, the way an upright screen always is |
|              | **Board edge**         | How the board meets the sky: a haze, the ground filling the screen, or a plain edge                |
|              | **Detailed world map** | Draws water, cliffs, towns and routes on the map. Off, each chunk shows its country at once        |
| **Play**     | **Keep the last ball** | A meeting opens on the ball you last threw, if you still carry one. Off, it opens on a Poke Ball   |
|              | **Box width**          | How wide the pokemon box is drawn: five, six or eight squares                                      |
| **Audio**    | **Sound**              | How loud the world is, a shiny's sparkle among it                                                  |
|              | **Music**              | Kept for when there is some. Nothing plays yet                                                     |

**Reduce motion** starts wherever the machine already stands: somebody who has
turned it on for their whole system has said it once already and is not asked
again. Walking, battles and eggs still move.

**Controls** start on W, A, S and D, Enter to act and M for the menu. Binding a
key another action already has hands that action the key you replaced. The
arrows always walk, whatever is bound.

The **theme**, light or dark, is kept apart from the rest. It is read before the
page paints so a dark screen never flashes white on the way in, and the switch
at the foot of the menu changes it as well.

**Security** belongs to the account rather than the machine. It holds an
authenticator app for two-factor sign-in and the passkeys the account accepts,
and nothing in it is shown until the password is typed again.

**About** is on the same page: what the game is, who wrote it, how far the dex
reaches, and the short version of the [credits](../credits.md).
