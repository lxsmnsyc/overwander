## Priority

Each move has a "priority" (or in technical terms, a "casting delay").

| Priority | Casting Delay |
| -------- | ------------- |
| +5       | 200ms         |
| +4       | 400ms         |
| +3       | 600ms         |
| +2       | 800ms         |
| +1       | 1s            |
| 0        | 1.2s          |
| -1       | 1.4s          |
| -2       | 1.6s          |
| -3       | 1.8s          |
| -4       | 2.0s          |
| -5       | 2.2s          |
| -6       | 2.4s          |
| -7       | 2.6s          |

Speed stat gradually reduces casting time from 0% to 50% at max stat (including overflows from boosts.).
