# Settings

**Settings** sits behind the menu, beside the bag and the box. Everything on it
belongs to the **machine rather than the account**: two browsers signed in as the
same trainer can disagree, and none of it reaches the server. Sign out and it is
still set the way you left it; open the game on a phone and that phone starts
fresh.

| Setting              | What it does                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Reduce motion**    | Holds the decoration still: dialog fades, transitions, and the idle a pokemon breathes at. Walking still moves |
| **Box columns**      | How wide the pokemon box is drawn: five, six or eight squares                                                  |
| **Clock**            | Whether times read as 24-hour or 12-hour                                                                       |
| **World time**       | Whether the menu bar names the period (Morning, Night) or the hour                                             |
| **Sound**, **Music** | Kept for when there is something to hear. Nothing makes a sound yet                                            |

**Reduce motion** starts wherever the machine already stands: somebody who has
turned it on for their whole system has said it once already and is not asked
again.

The **theme**, light or dark, is the one preference that lives elsewhere. It is
read before the page paints so a dark screen never flashes white on the way in.

**About** is on the same page: what the game is, who wrote it, and the short
version of the [credits](../credits.md).
