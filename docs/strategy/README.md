# Strategies

The larger plans, each written as batches that land one PR at a time. They run in the order below. A plan is deleted once every batch in it has shipped, and anything it leaves waiting moves to [todo.md](../todo.md).

| Plan | What it covers |
| --- | --- |
| [App logic](app-logic.md) | The game's logic moved out of the Solid components |
| [Zeniths](zeniths.md) | A Zenith for every eligible pokemon after Kanto, regional finals included |
| [Translations](translations.md) | Japanese and Spanish beside English |
| [Pixel effects](pixel-effects.md) | Battle and overworld effects drawn on the sprites' pixel grid |
| [Dungeons](dungeons.md) | Hideouts, explorable legendary lairs, Victory Road, the Elite Four tower, the Battle Frontier, the Endless Stair and the Companion Trail, as walkable floors |
| [Re-balancing](rebalance.md) | The league, syndicate and legend fights at level 100 with wider loadouts, signatures measured by simulation, the outliers reworked, and hand-written effects turned into moves the signature fires |
